# Backend - BK Parking MVP (TV1, TV2)

Thư mục này chứa mã nguồn **Java + Spring Boot 3 (Modular Monolith)**.

- Mã nguồn nền tảng của **TV1** hiện nằm trên nhánh **`feat/tv1-backend-platform`** và sẽ được merge vào `develop` sau khi review.
- **TV2** checkout từ `develop` (hoặc `feat/tv1-backend-platform`) sang nhánh `feat/tv2-backend-mvp` để tiếp tục phát triển.
